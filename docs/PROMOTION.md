## Short promotional post

Filter Laravel Eloquent queries without filling your controllers with conditions.

Query Filter Laravel moves filtering into reusable classes, with Laravel validation,
explicit filter allowlists, array inputs, relationship queries, and Livewire support.

Install it with Composer:

```shell
composer require plutuss/query-filter-laravel
```

Source and examples: https://github.com/plutuss/query-filter-laravel

## Detailed package description

Query Filter Laravel is an open-source PHP package for filtering Eloquent queries
using HTTP query parameters or explicitly supplied data. Define methods for the
filters your application needs, then apply them through a model scope.

Use Laravel validation rules to check strings, booleans, dates, and arrays of user
IDs before modifying the query. Declare allowed filter methods to keep public
helpers out of request-driven dispatch. Filter related records with Eloquent
relationships and read Livewire query string properties with the included trait.

The package includes an Artisan generator, examples, an upgrade guide, and 23
PHPUnit tests covering filtering, validation, class generation, Livewire parameters,
and real database queries. CI covers PHP 8.0–8.5 paired with Laravel 9–13.
Released under the MIT license.
